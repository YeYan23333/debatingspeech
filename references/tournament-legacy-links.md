# 新国辩赛事研究入口与来源说明

本文件是每次研究的起点，不是固定的"证据库"。实际写稿时仍须按具体辩题重新搜索、阅读和核验。

## 使用原则

-   优先寻找完整的一辩立论或可靠文字实录。
-   官方赛事账号的视频可用于定位具体比赛，但视频标题和赛程信息不能替代对立论内容的阅读。
-   第三方文字实录可能有转录错误；能与比赛视频、其他版本或原始证据交叉核验时，应进行核验。
-   比赛中的观点只用于学习论证方法。比赛稿里出现的数字和事实要独立追溯原始出处。
-   若只找到标题、赛程页或视频简介，在内部记录访问边界；必要的核验缺口简短说明，只有用户需要时才另给方法说明，不默认附渠道报告。

## 每次写稿时的检索建议

将用户辩题中的核心名词、判断词和争议关系拆成多组关键词，分别检索：

-   `“完整辩题” 国际华语辩论邀请赛`
-   `“完整辩题” 新国辩 一辩`
-   `“完整辩题” 立论 文字稿`
-   `“核心概念” 新国辩 辩论实录`
-   `site:bilibili.com 新国辩 “核心概念”`
-   若没有同题材料，检索论证类型相近的题目，如价值判断、因果归因、政策利弊或概念边界。

把搜索结果分成三类： 1. **完整可读稿件**：可供分析其论证地图； 2.
**可定位的比赛视频**：需确认是否能检查字幕或转录； 3.
**赛程、标题和题目列表**：只用作定位线索，不当作稿件内容或实证。

## 实证来源与赛事来源的区别

  ---------------------------------------------------------------------------------------------
  来源类型                可以支持什么                       不可以直接支持什么
  ----------------------- ---------------------------------- ----------------------------------
  新国辩文字实录/视频     论证结构、概念界定方式、攻防思路   未核验的数据、普遍事实或因果结论

  政府/国际组织原始数据   统计事实及其明确适用范围           超出统计口径的普遍化推论

  同行评审研究            研究设计与研究结果所支持的结论     将单一研究当作无争议的定论

  高质量新闻报道          事件背景、对原始来源的线索         未经核验的转述数字

  社交媒体/个人文章       观点线索、个案或社会话语样本       关键统计结论的唯一证据
  ---------------------------------------------------------------------------------------------
